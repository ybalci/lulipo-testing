# Test guide / Test rehberi

Please test naturally and report what you actually observe. No positive review or rating is required.

## Core checks

- Start level 1; verify 20 moves and a 10-second move timer.
- Swap by touch and drag. Try valid and invalid moves.
- Complete targets and check win/loss screens.
- Let the timer run out; confirm one move is deducted.
- Pause, background the app, lock the phone and resume.
- Check combos, special tiles and ice/lock obstacles when introduced.
- Try hammer/shuffle, demo rewards and closing the demo early.
- Switch Turkish/English and check clipping or untranslated text.
- Test offline and with sound both on and off.

## Google Play closed test

The Play enrollment and install links will be added after account setup. A GitHub installation is separate from the Play closed test. When available, use the Play links to join that test and remain opted in for its required period; provide genuine feedback during testing.
