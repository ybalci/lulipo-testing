# Test guide / Test rehberi

Play naturally and report actual observations. No positive review, five-star rating, purchase or scripted feedback is requested.

## Quick checks / Kısa kontroller

1. Start a new game in each mode: **Easy/Basit 120 s**, **Normal/Orta 90 s**, **Hard/Zor 75 s**. Hard keeps Normal's baseline move allowance; Easy adds moves.
2. Check that changing the home-screen choice updates its move/time preview. The choice should survive reopening; the game session should start at level 1.
3. Swap adjacent tiles by touch/drag. Invalid swaps should not consume a move.
4. Read the color, ice and lock goals. Check that ice quota and lock counts agree with the visible board.
5. Try finishing normally; report a board that seems impossible, including level, difficulty, remaining moves, and a screenshot. The fair-start guard checks a path with at least two initial moves spare; that is not a guarantee against mistakes or the human timer.
6. Let the round timer finish, then check the loss/continue options. Pause, background, lock and resume the phone.
7. Test Turkish/English, muted/audio play, clipping on your screen, and offline startup.
8. Try demo rewards and cancel them early. They must remain labelled demos; this build does not show real ads or charge real money.
9. Open the in-app privacy policy. It should load without Internet access.

## Google Play closed test / Kapalı test

The Google Play opt-in link will be shared separately when the track is ready. GitHub is optional and not part of the enrollment requirement. A GitHub APK download/installation **does not count** toward Google Play's closed-test tester period.

When the Play track is available, use the invited Google account for enrollment and the Play installation. Stay opted in for the required consecutive 14-day period if you choose to participate; provide genuine feedback while testing. No review/rating is required.

Play bağlantısı hazır olduğunda davetli Google hesabıyla teste katıl ve oyunu Google Play'den yükle. GitHub APK'sını indirmek veya kurmak bu teste kaydolmak anlamına gelmez ve 12 kişi / 14 gün koşuluna sayılmaz. GitHub hesabı gerekmez.
